# Проект автотестов для Saucedemo

## Установка зависимостей
Перед первым запуском установите необходимые библиотеки:
pip install -r requirements.txt

## Запуск тестов и формирование отчета
Чтобы запустить тесты и собрать данные для Allure, выполните в терминале:
pytest --alluredir=allure-results

## Просмотр отчета
Чтобы открыть сформированный отчет в браузере, выполните:
allure serve allure-results
